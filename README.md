# AI Mentor for Self-Learners

This is a simple prototype exploring how AI can guide learners step-by-step instead of just giving answers.

## Idea
Most AI tools respond to questions, but do not help learners think or progress gradually.

This project explores AI as a mentor that:
- Breaks learning into small steps
- Gives simple explanations
- Provides small tasks
- Asks follow-up questions

## Features
- Learning roadmap generation
- Beginner-friendly explanations
- Task-based learning approach

## Example
Input: "I want to learn Python"

Output:
- Step-by-step roadmap
- Explanation
- Practice tasks

## Goal
To explore how AI can support self-learners, especially those without access to teachers or structured education.

## Status
Early prototype (built for exploration)
